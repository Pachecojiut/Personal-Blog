# Personal Blog

Um espaço para ler, criar e compartilhar artigos.

## Projeto

**Project URL:** https://personal-blog-jxwp.onrender.com

## Como usar

### Visitante

Ao acessar o site, você pode:

* Visualizar os artigos publicados na página inicial.
* Clicar em um artigo para ler seu conteúdo completo.
* Consultar a data de publicação de cada artigo.

### Administrador

Para administrar os artigos:

1. Acesse a página de login.
2. Informe suas credenciais de administrador.
3. No painel administrativo, você poderá:

   * Criar novos artigos.
   * Editar artigos existentes.
   * Excluir artigos.

## Funcionalidades

* Visualização de artigos.
* Página individual para cada artigo.
* Login administrativo.
* Criação de artigos.
* Edição de artigos.
* Exclusão de artigos.
* Interface responsiva.
